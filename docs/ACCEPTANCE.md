## 已知限制与决策记录

| 编号 | 限制 | 影响 | 决策/缓解 |
| --- | --- | --- | --- |
| R1 | 代码关联/自动化/Desk/AI 数据无开放接口且内部接口后端不可达（T2） | D5/D8/D9/D11 运行时无法采集活跃度 | 按健康度标准 §7 判「无法核验」（绝不误判未配置）；购买判定正常（license）；人工补证路径预留 |
| R2 | fetchApp 前后端通道无平台级用户身份 | 无法做平台级强鉴权 | 白名单（401/403/隔离）+ 全量审计 + 只读 scope 三层控制；残余风险（知道成员 uuid 可冒充）已记录；平台提供身份头后可无缝升级 |
| R3 | demo App Center 生产更新仅支持 URL 输入 | 无法在 demo 环境验证生产上传 | dev 安装链路验证 .opkx 等价性（同一构建产物）；生产交付时客户提供文件托管或走官方渠道 |
| T13 | 终态判定按状态名关键词（done/完成/关闭/resolved） | 极端自定义状态名可能漏判 | 纳入规则版本；M6 双团队验收数据下判定正确；生产部署时结合客户状态配置校准 |
