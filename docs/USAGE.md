# 使用指南

## 如何找到插件

应用入口在**应用详情页的 tab**（不在工作台导航）：

```
左侧边栏「应用中心」→「已获取应用」→ 找到 customer-value-health → 点「管理应用」
→ 应用详情页顶部 tab「客户价值与健康度」
```

> 组织管理员路径等价：配置中心 → 应用管理 → 已获取应用 → customer-value-health → 管理应用。

应用已正式安装（v0.1.0 .opkx 上传，2026-08-21）：运行在 ONES 服务器上，不依赖任何本地服务；详情页含「基础信息 / 运行信息 / 客户价值与健康度」三个 tab。

## 使用流程

### 1. 首次进入：自动成为管理员

团队白名单为空时，**第一个打开页面的用户自动成为该团队的管理员（admin）**。
其他成员需要管理员添加后才能使用（见下方「白名单管理」）。

### 2. 生成报告快照

1. 点击「**生成报告快照**」按钮（默认统计近 90 天，对比前 90 天）
2. 观察进度条（采集项目 → 采集迭代 → 采集工作项 → 采集变更记录 → 计算指标 → 保存快照）
3. 完成后自动展示报告；也可在「历史快照」列表点击切换

### 3. 查看报告

- **六张指标卡**：项目（新建/活跃/状态分布）、Sprint、工作项（创建/首完/重开）、交付周期 P50/P75、协作（人工变更/参与人数）、计划兑现率
- **吞吐量趋势图**：按周展示创建/完成双柱
- **应用健康度矩阵**：12 个维度的成熟度判定（未配置/已配置未活跃/活跃使用/形成闭环/未购买/不适用/无法核验）
- **增购机会建议**：未购买模块单独列出（不计入健康度）

### 4. 编辑叙事（CSM）

报告摘要文本框可直接编辑，点「保存叙事」——只改叙事文案，**计算指标不可修改**，保存动作进审计日志。

### 5. 导出客户版 PDF

底部「导出客户版 PDF」面板：

1. 勾选板块（价值亮点/健康度矩阵/增购机会建议/口径说明）——增购建议默认不勾选，需显式确认
2. 点「确认并导出 PDF」
3. 出现下载链接（**1 小时内有效**，过期重新导出）

客户版 PDF 已脱敏：不含内部接口错误细节、用户标识；只含团队级聚合数据。

### 6. 白名单管理（管理员）

```
GET    /api/whitelist?teamID=<团队>&userID=<自己>          查看白名单
PUT    /api/whitelist  body: {teamID, userID, targetUserID, role}   添加成员
DELETE /api/whitelist?teamID=&userID=&targetUserID=        移除成员
```

角色：`admin`（可管理白名单）/ `member`（可生成/查看/导出）。

## 常见问题

**Q: 为什么部分健康度维度显示「无法核验」？**
代码集成、流程自动化、Desk、Assistant 四个维度的数据无开放接口（且内部接口不允许应用后端访问）。按设计规范，无法获取数据时判「无法核验」而非「未配置」——避免把接口不可用误报为未使用。

**Q: 生成报告显示全部是 0？**
默认统计近 90 天。若团队近期无活动（或数据时间分布特殊），换个周期重新生成即可验证。

**Q: PDF 下载链接失效？**
签名 URL 有效期 1 小时，重新点导出即可。

**Q: 权限报错「不在报告管理员白名单」？**
联系团队白名单管理员添加（见「白名单管理」）；若团队白名单为空，第一个访问的用户自动成为管理员。
