# Getting Started

## Overview

With the ONES Open Platform, you can build your own application to connect from other systems with your own customizations, including appearance and behavior to meet your specific business requirements.

A ONES Open Platform application (called an App) is essentially a web application that can be integrated into ONES. This means you have full control over your technology stack and infrastructure, as well as the ability to implement your own security measures and authentication through your code.

**Now let's start with a Hello World App in just a few minutes.**

## Create your app

1. Navigate to the directory where you want to create the app.

2. Create a new app.A new subdirectory with the app’s name will be created there.

```bash
ones create my-ones-app
```

3. The app will be created in the directory.
4. Change to the app subdirectory to see the app files:

```bash
cd my-ones-app
```

---

## Overview of the app structure

The app we created will display an setting page on the app's detail page when the app is installed in the ONES organization.

The hello world app has the following structure:

```bash
my-ones-app/
├── backend
│   ├── app.controller.ts
│   ├── app.module.ts
│   ├── app.service.ts
│   └── main.ts
├── eslint.config.mjs
├── nest-cli.json
├── opkx.json
├── package-lock.json
├── package.json
├── public
│   ├── favicon.ico
│   └── logo.svg
├── tsconfig.build.json
├── tsconfig.json
└── vite.config.ts
```

Let's take a look at the important files in the app's structure:

- opkx.json: The app's manifest file.
- package.json: The app's npm (node package manager) package file.
- tsconfig.json: The TypeScript configuration file.
- nest-cli.json: The NestJS configuration file for app's backend.
- vite.config.ts: The Vite configuration file for app's frontend.

## Change the app name

Edit the app's `opkx.json` file to change the app name to `"App for <your name>"`.

For example, _App for Jack_.

```json
{
  "app": {
    // Your app id should be generated by the CLI, it start with `app_` and be 20 characters long.
    "name": "App for Jack"
  }
}
```

:::note
Save the file and exit. If the app name contains spaces, that will be generated a opkx file with spaces in the name. We recommend using hyphens instead of spaces.
:::

## Build and package

Navigate to the app's top level directory, and use `ones build` to build the app and package the app into a `.opkx` file.

```bash
ones build
```

The built app will be generated a `<app-name>.opkx` file in the app's top level directory.

---

## Install your app in ONES

> Note: Check you have the permission to install apps in your ONES organization.

1. Navigate to the ONES On-Premises instance and find the **App Center** on the left sidebar.
2. Click the **App Center** to go to the **Installed apps** page.
3. Click the **Upload App** button and select the `<app-name>.opkx` file which is generated in the previous step.
4. Click the **Confirm** button to install the app.
5. The app will be installed and you can see it in the **Installed apps** page.

:::tip

- If you are using a ONES Cloud instance, you can see the [Install App via Link](../advanced/externally-hosted-app/externally-hosted-app.mdx) guide.
  :::
